All examples use the repository's real schemas and current enum values. Run SQL only against an authorized development/test database with the current migrations applied. The script uses SELECT and local variables, performs no persistent writes, and intentionally excludes password hashes and session tokens. Empty results are normal when a scenario has no data; reconciliation checks describe when zero rows indicate success.

The questions explain design choices and limitations; they are not verification results. Actual build, SQL, browser and deployment evidence belongs in `docs/TEST_REPORT.md`.
